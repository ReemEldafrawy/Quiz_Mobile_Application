# 📱 Quiz Mobile Application

A Flutter-based mobile application that allows users to test their knowledge through quizzes in different categories fetched from an external API.  

---

## 🚀 Features

- **User Authentication**  
  - Login and Register functionality.  
  - Secure session handling with Logout option.  

- **Categories from API**  
  - Fetches quiz categories dynamically from an external API.  
  - Users can select a category of their choice to start the quiz.  

- **Quiz Flow**  
  - Each quiz contains **4 multiple-choice questions**.  
  - After submission, answers are automatically validated.  
  - Score is calculated based on correct answers.  

- **Results & Ranking**  
  - Displays the **final score** at the end of the quiz.  
  - Shows the **user’s ranking/position** compared to others.  

---

## 🛠️ Technologies Used
- **Flutter** for cross-platform mobile development.  
- **Dart** as the programming language.  
- **External API** for quiz categories and questions.  

---

## 📂 Project Structure
- **Login Page** – Authenticate existing users.  
- **Register Page** – Create a new account.  
- **Categories Page** – Fetch and display categories from API.  
- **Quiz Page** – Show 4 questions for the selected category.  
- **Result Page** – Display score and ranking.
